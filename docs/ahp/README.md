# AHP — น้ำหนัก POI Score (D-54)

สคริปต์คำนวณน้ำหนักของ 5 ปัจจัยใน POI Score จากแบบสอบถามเปรียบเทียบเป็นคู่ (AHP)
แผนเต็มและเหตุผลอยู่ใน D-54 (`docs/DECISIONS.md`) และ `AHP-POI-weights-plan.pdf`

| ไฟล์ | ทำอะไร |
|---|---|
| `ahp.py` | อ่าน CSV คำตอบ → น้ำหนักรายคน + CR → รวมเฉพาะคนที่ CR < 0.10 แบบ AIP |
| `test_ahp.py` | ตรวจว่าได้ผลเท่าตัวอย่างที่ตีพิมพ์ใน R.W. Saaty (1987) |
| `create_form.gs` | Google Apps Script สร้างแบบสอบถาม (Google Form) — วางใน script.google.com แล้วรัน `createAhpForm` |

แบบสอบถามมี 3 ส่วน: ข้อมูลผู้ตอบ (คัดกรองว่าเคยวางแผนเที่ยวในไทยเอง) · คำอธิบายปัจจัยและสเกล · เปรียบเทียบ 10 คู่
1 คู่ = 1 หน้า 2 ข้อ: `k.1` ปัจจัยไหนสำคัญกว่า · `k.2` สำคัญกว่ามากแค่ไหน (สเกล 1–9, 1 = เท่ากันไม่ว่าข้อ k.1 เลือกอะไร)
→ ค่าใน CSV = +k.2 ถ้าเลือกปัจจัยแรกของคู่ · −k.2 ถ้าเลือกปัจจัยที่สอง · 1 ถ้า k.2 = 1 · ลำดับคู่ตรงกับคอลัมน์ CSV ด้านล่าง
`convert_form.py` แปลงไฟล์ที่ดาวน์โหลดจากแท็บคำตอบของฟอร์ม → CSV ของ `ahp.py` (เพิ่มคอลัมน์ `planned_trip`, `trips_last_year` ไว้คัดผู้ตอบ)

```bash
python convert_form.py google_export.csv responses.csv
python ahp.py responses.csv
```

ใช้ Python มาตรฐานอย่างเดียว (ทดสอบกับ Python 3.12) ไม่ต้องติดตั้งอะไรเพิ่ม

```bash
cd docs/ahp
python -m unittest -v test_ahp.py   # ตรวจสคริปต์
python ahp.py responses.csv         # คำนวณจากคำตอบจริง
```

## รูปแบบ CSV

1 แถว = ผู้ตอบ 1 คน · คอลัมน์ `respondent_id` + 10 คอลัมน์ของคู่ปัจจัย (ลำดับปัจจัยตรงกับ `WEIGHTS` ใน `poiScoreCalculator.ts`)

```
respondent_id,category-rating,category-distance,category-budget,category-weather,rating-distance,rating-budget,rating-weather,distance-budget,distance-weather,budget-weather
```

ค่าในคอลัมน์ `a-b`:
- `2`–`9` = a สำคัญกว่า b ระดับนั้น
- `-2`–`-9` = b สำคัญกว่า a ระดับนั้น
- `1` = สำคัญเท่ากัน

## ขั้นตอนและแหล่งอ้างอิง

| ขั้น | อ้างอิง |
|---|---|
| สเกล 1–9 | R.W. Saaty 1987, Table 1, น. 163 |
| จำนวนคู่ n(n−1)/2 | R.W. Saaty 1987, น. 163 |
| เมทริกซ์ส่วนกลับ a<sub>ji</sub> = 1/a<sub>ij</sub> | R.W. Saaty 1987, Axiom 1, น. 167 |
| น้ำหนักจาก principal eigenvector (ยกกำลังซ้ำจนลู่เข้า) | R.W. Saaty 1987, น. 170–171 |
| λmax = ผลรวมคอลัมน์ × w · CI = (λmax − n)/(n − 1) · CR = CI/RI · RI(5) = 1.12 · ยอมรับ CR < 0.10 | R.W. Saaty 1987, น. 171 |
| รวมผลแบบ AIP ด้วยค่าเฉลี่ยเรขาคณิต ผู้ตอบน้ำหนักเท่ากัน แล้ว normalize | Forman & Peniwati 1998, น. 167–168 |

ผลตรวจกับตัวอย่างของ Saaty: เมทริกซ์เกณฑ์เลือกมหาวิทยาลัยได้ 0.053 / 0.491 / 0.238 / 0.218 และ CR 0.02 ·
เมทริกซ์ LOCATION ได้ 0.115 / 0.402 / 0.284 / 0.163 / 0.037 และ CR 0.092 — ตรงกับเวกเตอร์ใน น. 166
(ข้อความ น. 165 พิมพ์ ACADEMICS 0.213 และ U. MICH 0.283 ซึ่งผลรวมไม่เท่ากับ 1)

## ยังไม่ได้ตัดสิน (รออาจารย์ — D-54)

- กลุ่มและจำนวนผู้ตอบ
- คำตอบที่ CR ไม่ผ่าน: ให้แก้ หรือตัดออก — สคริปต์ตอนนี้ **ตัดออก** และแสดงรายชื่อให้เห็น ถ้าเลือกให้แก้ คำตอบที่แก้แล้วก็ใช้สคริปต์เดิมได้
- ผลจาก pilot ของทีม **ห้ามใช้เป็นน้ำหนักจริง** (เป็นตัวเลขที่ทีมตั้งเอง)
