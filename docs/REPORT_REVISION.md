## 1. บทคัดย่อ / วัตถุประสงค์

- บทคัดย่อ + Abstract ประโยค Auto Trip ⚠️: "คัดเลือกและจัดเรียงด้วย Heuristic แบบ TSP" ไม่ครบ → คัดสถานที่ตาม POI Score จากสูงไปต่ำเท่าที่ยังเป็นไปได้ตามเวลา งบ เวลาเปิด-ปิด แล้วจัดลำดับรายวันด้วย nearest neighbor (ตรวจจาก `autoTripBuilder.ts` `schedulePlaces` / `findBestPlaceInsertion`) — ยังรอผู้ใช้นำข้อความไปใส่

## 3. ทบทวนวรรณกรรม (4)
- แทรก 4.1.3 AHP หลัง WSM → เลื่อนเลขหัวข้อเดิม 4.1.3–4.1.14 เป็น 4.1.4–4.1.15 · เนื้อหา 4.1.3 เป็นหลักการล้วน (คืออะไร ทำอย่างไร เอามาใช้ทำอะไร) อ้าง [3] ตัวเดียว (ผู้ใช้ตัดสิน 2026-11-05)
- 4.1.2: น้ำหนักมาจาก AHP
- 4.1.4 TSP ⚠️: ย่อหน้า "โครงงานนี้ประยุกต์ใช้ TSP" ผิด — โค้ดมีแค่จุดเริ่มต้น ไม่มีจุดสิ้นสุดตรึง (ที่ตรึงสองจุดและ Brute-force เป็นของโครงงานรุ่นก่อน) และ nearest neighbor เป็นวิธีประมาณ ไม่รับประกันสั้นที่สุด → เขียนว่าเริ่มจากจุดเริ่มต้นของผู้ใช้ เลือกที่ใกล้ที่สุดถัดไป (nearest neighbor) และลองแทรกสถานที่ทุกตำแหน่งเลือกเวลาเดินทางรวมน้อยสุด · ประโยคใน 4.1.10 เรื่อง Haversine เรียงเส้นทางตรงกับโค้ดแล้ว
- 4.1.5 Google Places: นำเข้าผ่านหน้า admin (ไม่ใช่ data pipeline) · ค้นด้วย "ชื่อ อำเภอ จังหวัด" + locationbias 1 km · ราคาจาก priceRange ไม่ใช่ price_level
- 4.1.10 Haversine (เลขเดิม 4.1.9): ORS เป็นหลัก Haversine เป็นตัวสำรอง และใช้เรียงเส้นทาง nearest neighbor ของ Auto Trip
- 4.1.12 ORS: ใช้ 3 ส่วน (POI distance, จัดเอง, Auto Trip)
- 4.1.14 Leaflet: ~40 KB (เว็บ leafletjs.com) · แผนที่ 4 หน้า (แนะนำ, จัดเอง, อัตโนมัติ, รายละเอียดแผน)
- 4.3 ทั้งหัวข้อ (ผู้ใช้ตัดสิน 2026-11-05): หัวข้อ = ชื่องานวิจัยเต็ม · เนื้อหา "งานวิจัยของ X และคณะ [n]" ตามลำดับ ทำอะไร → ทำไมทำ → ทำอย่างไร → ผล → โครงงานนี้นำมาใช้อย่างไรและตอนไหน (4.3.3–4.3.6 สั้น เน้นส่วนที่นำมาใช้ ทำไม) · งานวิจัยอยู่ที่ `Downloads/Research`
- 4.3.1 ⚠️: Lopes ให้ที่มา 5 ปัจจัย แต่ไม่ให้ค่าน้ำหนัก · เล่าการใช้งาน (เลือกเมือง ค้นหา กรอง เรียง เลือกสถานที่ ดูแผนรายการ/แผนที่ แชร์ อากาศ) เฉพาะที่เปเปอร์ระบุ ไม่เขียนว่าลากลงวัน · ส่วน Auto Trip: คัดสถานที่ตาม POI Score เท่าที่เป็นไปได้ตามเวลา งบ เวลาเปิด-ปิด + nearest neighbor + ลองแทรกทุกตำแหน่ง (ไม่ใช่ "TSP แทน OP" อย่างเดียว เพราะ Auto Trip คัดสถานที่เอง) · เวลาเดินทางจาก ORS
- 4.3.2: ลบ 35/25/15/15/10% ใส่น้ำหนัก AHP · อ่านจากไฟล์งานรุ่นก่อน (proposal ไม่มีผลทดสอบ → เขียนสมมติฐาน): TSP Brute-force ตรึงจุดเริ่ม/สิ้นสุด · Haversine แทน Routing API · แนะนำสถานที่ 8,000+ แห่ง เรียงตามจำนวนผู้ให้คะแนนแล้วคะแนนเฉลี่ย สูงสุด 30
